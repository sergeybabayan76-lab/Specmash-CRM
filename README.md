# ⚙️ СТО Спецмаш — CRM-система сервисного центра

Специализированная CRM-система для станции технического обслуживания, сервиса спецтехники, оборудования и грузового автотранспорта **«СТО Спецмаш»**.

---

## 🌟 Основные возможности

### 1. 👥 Сотрудники и ролевая модель доступа
В систему встроено управление персоналом СТО с разделением уровней ответственности:
* 👑 **Администратор (`admin`):**
  - Полный доступ ко всем модулям: финансовая аналитика, выручка, маржа, добавление/удаление сотрудников, настройки сервиса.
* 🛡️ **Модератор (`moderator`):**
  - Приемка техники, согласование смет, управление клиентами, воронка нарядов, склад запчастей и планировщик.
* 🔧 **Механик (`mechanic`):**
  - Исполнитель работ: просмотр закрепленных нарядов, перевод этапов ремонта, просмотр остатков на складе и списание деталей. Финансовая выручка скрыта для защиты коммерческой тайны.

Пользователи создаются администратором после входа. Для первого запуска можно задать учётные данные первичного администратора в `.env`; общих демо-паролей в приложении нет.

---

### 2. 🎨 Установка логотипа и брендинг СТО Спецмаш
* **Логотип в левом верхнем углу:**
  - Можно загрузить собственное изображение (PNG, JPG, SVG, WebP) либо указать прямую ссылку на картинку.
  - Логотип сохраняется в системе и мгновенно отображается на боковой панели.
  - Быстрый клик прямо по значку в левом верхнем углу открывает окно смены логотипа.
* **Название сервиса:**
  - Настройка названия организации в разделе *«Сотрудники & Роли»* с сохранением в базе данных.

---

### 3. 📋 Воронка нарядов: Канбан и Список в стиле Bitrix24
* **Два режима отображения сделок:**
  - 📋 **Интерактивный Канбан:** перемещение карточек заказ-нарядов методом Drag & Drop между 7 стадиями.
  - 📑 **Список как в Bitrix24:** табличное представление с **визуальной индикацией стадий (шевронный прогресс-бар)**:
    - Цветовая индикация пройденных, активного и будущих этапов воронки.
    - **Мгновенное изменение стадии сделки в 1 клик** прямо в строке списка (нажатием на шеврон или через встроенный селектор).
    - Быстрый поиск, фильтрация по стадии и суммарный расчет объемов выручки внизу таблицы.
* 7 этапов воронки: *Новые заявки ➔ Диагностика ➔ Согласование сметы ➔ В работе ➔ Ожидание запчастей ➔ Готово к выдаче ➔ Оплачено / Закрыто*.
* Связка с клиентом, конкретной машиной CASE из парка, суммой в AMD, приоритетом и ответственным мастером.

---

### 3.1 ⚙️ Страница настроек для администратора
* Доступна в меню боковой панели **«⚙️ Настройки СТО»** (для администратора):
  - **Реквизиты организации:** редактирование названия СТО Спецмаш, слогана/специализации, телефона (`+374...`), email, фактического адреса, ИНН и ответственного лица по умолчанию.
  - **Фирменный стиль и логотип:** предпросмотр логотипа в левом верхнем углу, загрузка файлов, ввод ссылок и сброс.
  - **Финансовые параметры и гарантия:** фиксированная валюта **AMD**, выбор гарантийного срока (3, 6, 12, 24 месяца).
  - **Резервное копирование и база данных:** выгрузка данных Supabase в JSON и просмотр статистики записей.

---

### 4. 🚜 База техники, связанная с базой клиентов
* Учет машин и оборудования: марка/модель, категория (*Спецтехника, Тяжелая карьерная, Сельхозтехника, Грузовые авто, ДГУ*), VIN / заводской номер, год выпуска, наработка (моточасы/пробег).
* **История обслуживания:** в карточке клиента и машины сохраняются все предыдущие заказ-наряды.

---

### 5. 📦 Складской учет запчастей и списание под наряды
* Учет номенклатуры (артикулы SKU, ячейки хранения, закупочные и розничные цены, остатки).
* **Автоматический контроль дефицита:** предупреждения, если остаток упал ниже минимального порога.
* **Списание со склада в заказ-наряд:** добавление запчастей прямо в сделку с авто-списанием и расчетом себестоимости.
* Быстрый приход и списание (`± Кол-во`) с фиксацией комментариев.

---

### 6. 💰 Финансовая аналитика и расчет выручки
* **Общая выручка** по закрытым заказ-нарядам.
* **Себестоимость и чистая прибыль** с расчетом маржинальности в %.
* Оценка товарных запасов на складе.
* Рейтинг топ-клиентов по объему выручки.

---

### 7. ⏰ Задачи, напоминания и планировщик
* Контроль дедлайнов, звонков клиентам, поставок запчастей и выдачи техники.
* Визуальная подсветка просроченных задач (красным цветом).
* Выполнение задач в 1 клик.

---

### 8. 📥 Импорт и экспорт данных (Excel / CSV)
* Выгрузка клиентов, техники, склада, нарядов и сотрудников в CSV с поддержкой UTF-8 BOM (безупречно открывается в Microsoft Excel).
* Пакетный импорт клиентов и запчастей из файлов CSV.

## ⚡ Запуск программы

### Первое подключение новой базы Supabase:
1. Создайте новый проект Supabase.
2. Откройте **SQL Editor**, вставьте содержимое [`database/schema.sql`](./database/schema.sql) и выполните его. Скрипт создаёт пустые таблицы, включает RLS и не вставляет демо-данные.
3. Скопируйте [`.env.example`](./.env.example) в `.env`. Заполните `SUPABASE_URL`, серверный `SUPABASE_KEY` (секретный `sb_secret_...` или legacy `service_role` key) и `APP_SESSION_SECRET` случайной строкой не короче 32 символов.
4. Чтобы создать первого администратора, задайте `BOOTSTRAP_ADMIN_USERNAME` и `BOOTSTRAP_ADMIN_PASSWORD` (не короче 12 символов). При первом старте он будет добавлен только если таблица `users` пуста. После первого успешного запуска удалите пароль bootstrap из окружения. Если оставить обе переменные пустыми, база останется пустой и войти будет нельзя, пока не появится пользователь.
5. Никогда не используйте publishable/anon key в `SUPABASE_KEY`, не отправляйте секретные значения в браузер или чат и не добавляйте `.env` в Git.

### Быстрый запуск (Windows):
После настройки `.env` дважды щёлкните [`start.bat`](./start.bat). Он запустит сервер и откроет браузер:
**`http://localhost:8000`**

### Через командную строку:
```powershell
cd C:\path\to\Specmash-CRM
.venv\Scripts\python.exe -m uvicorn server:app --host 127.0.0.1 --port 8000 --reload
```

API защищён подписанной HttpOnly-сессией; ключ Supabase остаётся на сервере. Kanban-события проходят через авторизованный WebSocket приложения.

## 🚀 Развертывание в Vercel (One-Click Deployment из GitHub)

Проект полностью сконфигурирован для серверлесс-развертывания в **Vercel** (`@vercel/python` Serverless Functions) напрямую из репозитория GitHub:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fsergeybabayan76-lab%2FSpecmash-CRM)

* **Файлы конфигурации:**
  - `vercel.json` — конфигурация маршрутизации и Serverless билдера.
  - `api/index.py` — серверлесс-точка входа FastAPI для Vercel.
  - `database/schema.sql` — структура пустой базы Supabase PostgreSQL и права доступа.

### Как развернуть проект в Vercel в 1 клик:
1. Нажмите на кнопку выше **[Deploy with Vercel](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fsergeybabayan76-lab%2FSpecmash-CRM)** (или перейдите в [Vercel New Project](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fsergeybabayan76-lab%2FSpecmash-CRM)).
2. Выберите репозиторий `sergeybabayan76-lab/Specmash-CRM` и нажмите **Import**.
3. Нажмите **Deploy** — Vercel автоматически установит зависимости из `requirements.txt` и запустит приложение.
4. Выполните `database/schema.sql` в SQL Editor Supabase и задайте в Vercel Environment Variables `SUPABASE_URL`, `SUPABASE_KEY`, `APP_SESSION_SECRET`; для первого администратора также задайте `BOOTSTRAP_ADMIN_USERNAME` и `BOOTSTRAP_ADMIN_PASSWORD`.
5. **Автоматический CD (Continuous Deployment):** Каждый `git push` в ветку `main` на GitHub будет автоматически запускать новую сборку и обновлять работающее приложение в Vercel без простоев.
